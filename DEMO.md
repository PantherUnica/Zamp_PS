# Five-minute demo

**Before you record:**
- Sign in as an admin and, under Team, add a second account as **Reviewer**. You approve as the reviewer, since an owner can't approve their own vendor.
- Use your own email as the vendor contact so you can show the emails arriving.

| Time | Do | Say |
|---|---|---|
| 0:00 | Landing → sign in → Overview | "One place from the first call to an approved supplier. Orange means a human is needed." |
| 0:20 | Calls → Log a call → **Use demo transcript** → Analyse | "The agent turns a call into vendor details, objections, coaching and a risk flag: she wants payments to a sister company." Apply → creates the vendor. |
| 1:00 | New vendor → Demo vendor: **Northwind** → Create and send link | Show the invitation in your inbox. |
| 1:20 | Open link → **Fill demo details** → Review → Submit | "No account. Autosaves. GSTIN, PAN and IFSC are checked as you type; the IFSC is looked up in RBI branch data." |
| 1:50 | Live run | "AI reads, rules decide, and every check shows where its evidence came from. Registry checks say *not connected*, never *passed*." |
| 2:20 | Sign in as the reviewer → Review queue → Northwind → Approve | "Even a clean case needs a person. The decision and note are in the audit trail." |
| 2:50 | **Kestrel** (no cheque) → submit | "Objective issue, so the request is emailed automatically." Show the email → open the link → **Attach requested demo file** → Resubmit → v2 clears. |
| 3:40 | **Brightline** → submit | "The cheque is in another company's name: that needs judgment. The agent drafted a correction; the salesperson edits and sends it." Show the draft on the vendor page. |
| 4:20 | **Albion** → submit | "The GSTIN belongs to Maharashtra and to a different PAN, and the certificate shows another number. Approval is blocked." |
| 4:45 | Emails page, then Overview | "Every email has a delivery status and can be retried. Every action is logged." |
